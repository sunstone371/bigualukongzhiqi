# 接线说明

> 丝印以 NodeMCU / Wemos D1 mini 为例（两者一致）。GPIO 编号与丝印对应：D0=16、D1=5、D2=4、D4=2、D5=14、D6=12、D7=13、D8=15。

## 客厅端（显示 / 测温 / 调温）

```
ESP8266                OLED (SSD1306 I2C)
┌──────────┐          ┌─────────────┐
│      3V3 ├──────────┤ VCC         │
│      GND ├──────────┤ GND         │
│  D1 (5)  ├──────────┤ SCL         │
│  D2 (4)  ├──────────┤ SDA         │
└──────────┘          └─────────────┘

ESP8266                DHT11/DHT22
┌──────────┐          ┌─────────────┐
│      3V3 ├──────────┤ VCC         │
│      GND ├──────────┤ GND         │
│  D4 (2)  ├──────────┤ DATA        │
└──────────┘          └─────────────┘
              （裸传感器需 4.7~10kΩ 上拉到 3V3，三针模块通常自带）

ESP8266                按钮 ×3（另一端全部接 GND）
┌──────────┐
│  D5 (14) ├── SET （进入/保存设置）
│  D6 (12) ├── UP   （+0.5℃，长按连发）
│  D7 (13) ├── DOWN （-0.5℃，长按连发）
└──────────┘
（固件内部上拉，按下为低电平）
```

## 壁挂炉端（继电器执行器）

```
ESP8266                继电器模块
┌──────────┐          ┌──────────────────┐
│  VIN (5V)├──────────┤ VCC              │
│      GND ├──────────┤ GND（共地）      │
│  D5 (14) ├──[电平适配]── IN            │
└──────────┘          └──────────────────┘

继电器触点             壁挂炉温控器端子
┌──────────┐          ┌──────────────────┐
│      COM  ├──────────┤ TA/室温控制器端子1│
│       NO  ├──────────┤ TA/室温控制器端子2│
└──────────┘          └──────────────────┘
（干接点：闭合 = 呼叫供暖）
```

### 电平适配（3.3V ESP8266 → 5V 低触发光耦模块）

三种方案任选其一：

**方案 1：模块触发极性跳线切 HIGH**（如果你的模块有）

**方案 2：串联 1N4148 二极管（推荐，1 个元件解决）**
```
ESP D5 ──▶|── 继电器 IN     （▶| = 二极管，阳极朝 ESP，环标端朝 IN）
```
- 吸合：ESP 输出低 → 二极管导通 → IN≈0.6V → 光耦点亮
- 断开：ESP 输出 3.3V → 二极管反偏截止 → 零电流，彻底断开

**方案 3：NPN 三极管反相**
```
ESP D5 ──[1kΩ]── 基极(S8050)
                 发射极 ── GND
                 集电极 ── 继电器 IN
```
逻辑反相：ESP 高 = 吸合。需把 `RELAY_ACTIVE_LOW` 改为 `0`。

## 指示灯

- 壁挂炉端板载 LED（GPIO2）：**慢闪（500ms）= 链路正常；快闪（100ms）= 链路超时**
- 客厅端 OLED 底栏：HEATING / IDLE / NO LINK

## 引脚选择禁忌（重要）

| 引脚 | 问题 |
|---|---|
| GPIO15 (D8) | boot strap 引脚 + 板载下拉：每次上电/复位瞬间输出低，低电平触发继电器会**误吸合** |
| GPIO0 (D3) | boot strap（按住进刷机模式） |
| GPIO16 (D0) | RTC 引脚：无内部上拉、不支持开漏/中断，仅可做普通输出 |
| GPIO1/3 | 串口 TX/RX，被日志占用 |
