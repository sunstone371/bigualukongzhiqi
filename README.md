# bigualukongzhiqi 壁挂炉温控器

一个低价、易上手的壁挂炉室温控制器。两块 ESP8266 通过 ESP-NOW 无线通联：**客厅端**测量并显示室温/湿度、按键设定目标温度；**壁挂炉端**按回差控制继电器呼叫供暖。无需路由器、无需云端、掉电记忆设定值。

## 功能特性

- **无线通联**：ESP-NOW + SoftAP 信道锁定方案（不依赖家里 WiFi，两端上电自动配对，无需抄 MAC 地址）
- **OLED 显示**：大字号室温、湿度、目标温度、炉端状态（HEATING / IDLE / NO LINK）
- **按键调温**：SET 进入/保存设置界面，UP/DOWN ±0.5℃（长按连发），范围 5.0~30.0℃，15 秒无操作自动保存
- **掉电记忆**：目标温度存 EEPROM
- **回差控制**：室温 ≤ 设定−0.5℃ 吸合呼叫供暖，≥ 设定+0.5℃ 断开，避免频繁启停
- **防短循环保护**：继电器最短运行 60 秒、断开→再次吸合间隔 ≥180 秒
- **安全机制**：
  - 温湿度传感器故障 → 立即停止呼叫供暖
  - 链路超时 90 秒收不到遥测 → 安全停机并告警（炉端 LED 快闪）
  - 上电/重启继电器默认断开
- **自愈能力**：链路超时后每 30 秒自动重建 ESP-NOW；持续超时 3 分钟自动重启整机恢复；两端均有周期心跳日志（串口 115200）

## 接线

详细接线表见 [docs/wiring.md](docs/wiring.md)。

**客厅端（NodeMCu 丝印）**：

| 模块 | 引脚 | 接到 |
|---|---|---|
| OLED (I2C) | VCC / GND / SCL / SDA | 3V3 / GND / **D1** (GPIO5) / **D2** (GPIO4) |
| DHT11/22 | VCC / GND / DATA | 3V3 / GND / **D4** (GPIO2) |
| 按钮 SET / UP / DOWN | 一端 | **D5** (GPIO14) / **D6** (GPIO12) / **D7** (GPIO13)，另一端全部接 GND |

**壁挂炉端**：

| 模块 | 引脚 | 接到 |
|---|---|---|
| 继电器模块 | VCC / GND / IN | 5V(VIN) / GND / **D5** (GPIO14) |
| 继电器触点 | COM + NO | 壁挂炉的**外接室温控制器（TA/温控器）干接点端子** |

## ⚠️ 重要：继电器选型与电平适配

**ESP8266 是 3.3V 逻辑**。市面上常见的 5V 光耦继电器模块是低电平触发，直接用 3.3V 高电平"断开"时，光耦两端仍有 1.7V 压差会**微导通导致关不断**（本项目实测踩坑，见 [docs/troubleshooting.md](docs/troubleshooting.md)）。三种解决方案任选其一：

1. 模块带 HIGH/LOW 触发跳线 → 切到 **HIGH 触发**，并把代码 `RELAY_ACTIVE_LOW` 改为 `0`
2. **串一个 1N4148 二极管**：ESP D5 → 二极管阳极，阴极 → 继电器 IN（固件无需改动）
3. NPN 三极管（S8050 + 1kΩ 基极电阻）反相驱动，`RELAY_ACTIVE_LOW` 改为 `0`

另外**不要用 GPIO15 (D8)** 驱动继电器——它是 boot strap 引脚且板载下拉，每次上电/复位会瞬间吸合。

## ⚠️ 安全须知

1. **燃气壁挂炉必须接在它的"外接室温控制器"干接点端子上**（接线排上标 TA / ROOM / 温控 的两个低压端子，闭合 = 呼叫供暖）。**绝对不要**改动锅炉内部电路或用继电器直接切断强电！
2. 若你的锅炉没有温控器端子，请找专业人员处理。
3. 失联 90 秒会自动停止供暖（安全优先）；冬季长期离家请保留锅炉自身的防冻模式。
4. 强电操作有触电风险，请务必断电操作。

## 烧录

两个文件夹各是一块板的完整固件（单文件 Arduino 程序，全部中文注释）：

- `livingroom_unit/main.cpp` → 客厅端 ESP8266
- `boiler_unit/main.cpp` → 壁挂炉端 ESP8266

推荐使用 [aily Coder](https://yiyu.pro)（本项目开发工具）：

1. 新建 ESP8266 项目，把对应 `main.cpp` 内容放入 `sketch/src/main.cpp`
2. 客厅端项目需安装库：U8g2（OLED）、Adafruit DHT（温湿度）
3. 分别编译、上传到两块板（115200 串口可看心跳/调试日志）

用 Arduino IDE 也一样：把 `main.cpp` 内容粘贴进 `.ino` 草图，安装 `U8g2` 和 `DHT sensor library`（含 Adafruit Unified Sensor），选 ESP8266 板型编译上传。

所有参数都集中在各 `main.cpp` 顶部的宏定义处：

| 宏 | 默认 | 说明 |
|---|---|---|

| `OLED_SH1106`（客厅端） | 0 | 1.3 寸 SH1106 屏改为 1 |

## 工作原理

- **通信**：壁挂炉端开 SoftAP（`BoilerLink`，锁定 WiFi 信道），客厅端 STA 连接该 AP 后信道同步——这解决了 ESP8266 空闲 STA 信道随机漂移导致 ESP-NOW 掉线的问题。数据用 ESP-NOW 广播：客厅端每 5 秒发遥测包（温度/湿度/设定值），炉端每包回状态包（继电器状态）。
- **协议**：17 字节自定义包（魔数 + 链路号 + 类型 + 序号 + 标志 + 温/湿/设定 ×10 + 继电器状态 + CRC16-CCITT），非法包一律丢弃。
- **控制**：见上文"功能特性"中的回差与保护逻辑。

开发过程中踩过的坑与排查记录（信道漂移、strap 引脚、5V 继电器微导通、millis 时序等）都在 [docs/troubleshooting.md](docs/troubleshooting.md)，复刻前建议阅读。
